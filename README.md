# PanBox · 多网盘统一下载管家

Windows 桌面程序：把网盘**分享链接**粘进来 → 解析 → 多线程、断点续传下载，带实时进度与速度。
自带浏览器插件，可以在网页上直接右键「用 PanBox 下载」。

> **定位**：用**你自己的账号**，拿到**你这个账号本来应有的速度**。
> 它**不是**破解限速器 —— 网盘限速是服务端按账号等级发令牌决定的，客户端改不了。

📦 下载：https://github.com/Ygq156/PanBox/releases/latest

## 快速开始

1. 双击 `PanBox-x.y.z-portable.exe`（免安装），或运行 `PanBox Setup x.y.z.exe` 安装。
   首次运行 Windows 可能提示"未知发布者" → 「更多信息」→「仍要运行」。
2. 把分享链接粘进顶部输入框（**一行一个，支持批量**），有提取码填右边。
3. 点「解析」→ 勾选文件 → 「开始下载」。默认存到 `<系统下载目录>\PanBox`。

### 为什么每个网盘的连接数不一样

实测结论：**"账号级总量限速"只对百度成立。**

- **夸克 / UC**：按**每条 TCP 连接**发额度（夸克 ≈50 KB/s、UC ≈64 KB/s），**连接数就是速度**。
  aria2 的 `--max-connection-per-server` 上限只有 16，所以 PanBox 自带一个**分段引擎**
  （`electron/core/segmentDownloader.js`），给这两家开 **96 连接**，0.8 → **4.4–5.3 MB/s**。
- **百度**：真正的**账号级总量**限速。1/2/4/8 连接都是 0.08 MB/s，16+ 直接 **403**，多开只会招来
  几小时到几天的**惩罚性降速** → 强制 `split=1`，不走分段引擎。想要快只能开会员，或在官方 PC 客户端
  打开「设置 → 传输 → 下载提速」（免费，但**没有 API** 可以程序化开启）。
- **迅雷**：8 连接之后到顶（1/2/4/8 = 0.15/0.29/0.56/**1.09** MB/s），16+ 开始零星 503 → 故意压在 8。
- **蓝奏云 / 直链 / 123 云盘**：不按连接发额度，多开只是抗抖动。

连接数都在「设置 → 分段引擎连接数」里改。

### 为什么夸克 / UC / 迅雷 / 百度需要登录

- **夸克**：CDN 校验 `__puus`，它是网页 JS 动态生成的；游客直链（`dl-guest-*`）一律 **412**。
- **UC**：CDN 把 Referer/Cookie/IP 拿去做回调鉴权，游客态回 **403 `require login [auth not found]`**。
- **迅雷**：转存和取直链的接口匿名一律 **401**；且取直链的 `client_id` 必须与网页版一致，
  直链**只认安卓 Dalvik UA**（浏览器 UA 十几秒后回 503）。
- **百度**：dlink **必须**带 `User-Agent: pan.baidu.com`，且按账号维度限速。

四家都走「用你自己的账号**转存到 `/PanBox` → 取直链 → 下载 → 自动删除副本**」。

**登录方式**：设置 →「网盘账号」→ 点「登录{网盘名}」→ 在弹窗里正常登录，检测到登录态后自动关闭并写入。
也可以手动粘 Cookie。

### 不会污染你的网盘

转存**之前**先给目标目录拍快照，只有「转存之后新出现的文件」才登记待删 —— **你自己原有的同名文件绝不会被误删**。
回收时机覆盖三种：任务完成、下载途中撤销任务、退出程序。**未完成且还在队列里的不回收**（还要续传）。

## 网络出口（下 GitHub / 境外资源必看）

**默认跟随 Windows 系统代理，并且会自动选路。** 这一条直接决定你下境外资源是几十 KB/s 还是 10 MB/s。

同一条 GitHub 66 MB 直链实测：

| 出口 | 结果 |
|---|---|
| 直连 `github.com` | **0 B/s**（SNI 层被重置，且是**间歇性**的） |
| 直连 CDN | 能连上，但单连接只有 **0.03–0.04 MB/s**，且"先冲一阵再长时间不动" |
| 走系统代理 | **9.5 MB/s**，66 MB 用 7 秒，字节数精确 |
| 直连 + 停顿重连 + 128 连接 | **2.08 MB/s**，66 MB 用 32 秒 |

> 顺便测了 NDM（常被拿来对比）：它是 **32 条直连 socket、完全不经过代理**，约 1.9 MB/s。
> 没有魔法，就是"单连接只有 0.06 MB/s，那就开 32 条"。所以本机走代理的 PanBox 比直连的 NDM 快 4~5 倍。

**不用代理也能下**：直连的瓶颈不是带宽（峰值能到 11 MB/s，但平均只有 0.9），原因是①线路会先冲一阵
再几十秒不动 → **空档看门狗**：超过 3 秒没有新数据就掐掉换新连接重下；②`github.com` 那一跳间歇性被重置
→ **重定向只解一次**，之后所有分片直接打终点 CDN。修完 32/64/128 连接是 1.34 / 2.12 / 3.02 MB/s。

设置项：**跟随 Windows 系统代理**（默认，读注册表，Clash 换端口自动跟）/ **手动指定** / **不使用代理**。
分段引擎在探测阶段按「代理 → 直连」各试最多 3 次，选中哪条整条任务都用它；任务行会标出「· 走代理」。
代理**只给普通直链任务** —— 网盘直链可能按 IP 授权，不拿它冒险。

## 浏览器插件

自带插件（`resources/extension/`，随安装包发布）：右键链接 / 视频 / 音频 → 「用 PanBox 下载」，
或**接管浏览器的下载**（浏览器里点任何下载都会转进 PanBox；PanBox 没运行就放回浏览器）。

**装插件**：PanBox →「设置 → 浏览器插件 → 打开插件文件夹」→ 浏览器打开 `chrome://extensions`
（Edge 是 `edge://extensions`）→ 开**开发者模式** → **加载已解压的扩展程序** → 选那个 `extension` 文件夹
→ 点插件图标 → 「重新配对」。
> 更新插件后要回扩展页点一次**「重新加载」**（已解压的扩展不会自动更新，Chrome 137 起命令行侧载也被禁用）。

**怎么用**：
- **页面左上角的「N 个文件」悬浮面板**：列出这一页能下的东西 —— 正在播放的**视频/音频真实地址**、
  `.m3u8`、`.ts` / `.m4s` 分片、页面里的 `.zip` / `.apk` / `.pdf` 链接，点「下载」直接进 PanBox。可拖动。
  - **按响应头 `Content-Type` 认媒体，不看后缀**。抖音的地址路径里根本没有 `.mp4`，只按后缀永远找不到。
  - **SPA 换视频自动重扫**（抖音、B 站靠 `pushState` 换内容，页面不重新加载）。
  - **✕ 只是暂时收起**，发现新内容会自己回来。
  - B 站 / YouTube 用 MSE，`<video>` 上是 `blob:` 地址，**任何下载器都拿不到**；面板会改列抓到的分片。
- **接管浏览器下载**（默认开启）：GitHub 的 Download ZIP 这类会直接转进 PanBox。

投递过来的是**网盘分享链接**时，PanBox 不会擅自决定下什么 —— 它把链接预填进输入框，让你自己勾选。

## 自定义解析接口（可选，先读合规边界）

内置解析的天花板是**你自己账号的档位**（百度 0.10 MB/s、迅雷 1.1、夸克 4.4 / UC 5.3）。
如果你愿意信任某个第三方解析服务，可以配「设置 → 高级：解析接口」让它转发（Motrix / Gopeed 那类
"不用登录还跑满"就是这么做的 —— 解析站用自己的 SVIP 账号取链，谁付带宽取决于你配的服务）。

- 地址与请求体支持 `{url}` `{pwd}` `{shareId}` `{netdisk}` 占位符；POST / GET 都行。
- 响应里的 `url` / `dlink` / `directLink` / `downLink` / `download_url` / `link` / `real_url` …
  与数组、`data.list[0].url` 这类嵌套都能自动识别；认不出来可以手填字段路径；302 也会自动跟。
- 配了就优先走接口，接口挂了**自动退回内置解析**；走接口拿到的直链**不受百度单线程限制**。
- 首次启用必须勾选**用户承诺**，不勾不能保存。

### 合规边界

PanBox 是**下载客户端**，不做也不会做：内置/推荐任何解析站；代收费用或分成；破解会员 / 秒传 / 伪造身份 /
变速外挂（对 2026 年的服务端限速模型已失效，且 `PanDownload` 作者 2020 年因《刑法》第 285 条被捕）；
帮助批量获取或转售他人资源。

**用户承诺**：只用它下载**你自己有权下载**的内容；不用于规避会员/限速机制，不用于获取、传播、转售他人
受版权保护的资源；接口地址由你自己提供并自行确认合法性 —— PanBox 只做 HTTP 转发，不看、不存、不校验
它返回什么。填了提取码时提取码会随分享链接一起发给该接口；**你自己的网盘 Cookie 只在本机使用，不会发往接口**。

## 常见问题

**Q：为什么速度没有突破网盘限制？**
A：做不到。限速是**服务端**按账号等级决定的。但"加线程有没有用"要分盘看，PanBox 的做法是**逐盘标定**
（见上面「为什么每个网盘的连接数不一样」）。

**Q：那 PanBox 有什么用？**
A：① 一个入口管所有网盘；② 批量解析、批量下载、统一队列；③ 逐盘标定的连接数 + 断点续传 + 实时速度；
④ 对不限速的盘是真满速；⑤ 自动清理转存副本，不污染你的网盘。

**Q：会读取 / 上传我的账号信息吗？**
A：不会。凭证只存在本机 `%APPDATA%\PanBox\settings.json`，所有请求直接发往网盘官方接口，没有中间服务器。

## 技术栈与构建

- **壳**：Electron 44（`contextIsolation: true`、`nodeIntegration: false`）
- **界面**：React 19 + TypeScript + Vite 8
- **下载引擎**：内置 **aria2 1.37.0**（JSON-RPC 控制，随机 token，只监听 `127.0.0.1`）+ 自研分段引擎
- **解析层**：`electron/parsers/` 下每个网盘一个纯 Node 模块

```bash
npm install
npm run build:renderer                 # 渲染层
npx tsc --noEmit -p tsconfig.json      # 类型检查
npm run pack                           # 打包 NSIS + portable
```

`resources/aria2/aria2c.exe` **不在仓库里**，需自行下载 aria2 1.37.0 win-64 放到该路径。

```
  parsers/  index.js  lanzou.js  ilanzou.js  clouddrive.js(夸克+UC)  pan123.js  baidu.js

```

### 已知限制

- 夸克/UC/百度/迅雷**必须登录**，游客直链会被 CDN 拒绝（412 / 403 / 401）。
- **账号级限速是硬天花板**：内置解析拿到的速度取决于你自己账号的档位。
- **123 云盘**受分享者每月 10 GB 提取配额限制。
- **天翼 / 移动云盘**尚未实现。
- 未做代码签名，首次运行会触发 SmartScreen。

### 解析规格来源（许可证要求的署名）

PanBox 借鉴的是以下项目公开的**本地解析算法实现**（用于 `electron/parsers/` 里的离线计算），
**不调用**、**不推荐**、也不链接它们的任何在线服务。署名不代表对其服务可用性与合规性的背书。

- 蓝奏云 / 蓝奏优享 / 123 云盘：`qaiu/netdisk-fast-download`（`LzTool.java` / `IzTool.java` / `AESUtils.java` / 签名算法）
- 夸克 / UC：`qaiu/netdisk-fast-download`（`QkTool.java` / `UcTool.java`）、`muyan556/gopeed-extension-quark`（MIT）
- 百度网盘：`pan.baidu.com/union` 开放平台文档 + 社区实现
