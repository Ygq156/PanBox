# PanBox · 多网盘统一下载管家

Windows 桌面程序：把网盘分享链接粘进来 → 解析 → 多线程、断点续传下载，带实时进度与速度。
自带浏览器插件，网页上可以右键「用 PanBox 下载」，也能接管浏览器下载。

> **它是什么**：用你自己的账号，拿到你这个账号本来应有的速度。
> **它不是什么**：破解限速器。限速由网盘服务端按账号等级决定，客户端改不了。

📦 下载：https://github.com/Ygq156/PanBox/releases/latest

## 快速开始

1. 双击 `PanBox-x.y.z-portable.exe`（免安装），或运行 `PanBox-Setup-x.y.z.exe` 安装。
   首次运行 Windows 可能提示"未知发布者" → 「更多信息」→「仍要运行」。
2. 把分享链接粘进顶部输入框（**一行一个，支持批量**），有提取码填右边。
3. 点「解析」→ 勾选文件 → 「开始下载」。默认就存在系统「下载」目录里，不额外建文件夹。
   队列里已完成的点 ✕ 会问一句：放进回收站（可还原）还是彻底删除（连磁盘文件一起删）。

|---|---|---|---|---|

| 夸克网盘 | ✅ | ✅ | 需要 | **4.4 MB/s**（96 连接） |
| UC 网盘 | ✅ | ✅ | 需要 | **5.3 MB/s**（96 连接） |

| 百度网盘 | ✅ | ✅ | 下载需要 | **0.10 MB/s**（账号级限速，强制单线程） |
| 迅雷云盘 | ✅ | ✅ | 需要 | **1.1 MB/s**（8 连接） |
| 阿里云盘 | ✅ | ✅ | 下载需要 | 未实测（列目录不用登录，取下载地址要登录） |
| 天翼云盘 | ✅ | ✅ | 下载需要 | 未实测（单文件分享不用登录；文件夹分享与取下载地址要登录） |
| 移动云盘 | ✅ | ✅ | 下载需要 | 未实测（列目录不用登录，取下载地址要登录） |
| 直链 / 境外资源 | ✅ | ✅ | 不需要 | 看源站；GitHub 走代理 **9.5 MB/s** |
| 论文站（MDPI / SSRN） | ✅ | ✅ | 不需要 | 各自开放获取与预签名地址，看站点 |
| 115 / 微云 | ⬜ 未实现 | ⬜ | — | — |

**连接数为什么逐盘不同**：实测"账号级总量限速"只对百度成立。夸克 / UC 按**每条 TCP 连接**发额度
（≈50 KB/s、≈64 KB/s），**连接数就是速度** —— aria2 的每服务器连接上限只有 16，所以夸克 / UC 走
PanBox 自带的**分段引擎**开到 **96 连接**（0.8 → 4.4–5.3 MB/s）。百度是真正的账号级限速，16 连接以上
直接 403 且会招来**惩罚性降速**，所以强制单线程。迅雷 8 连接到顶。以上都在「设置 → 分段引擎连接数」里改。

**登录方式**：设置 →「网盘账号」→「登录{网盘名}」→ 在弹窗里正常登录，检测到登录态后自动关闭并写入；
也可以手动粘 Cookie。四家需要登录的盘都走「用你自己的账号转存到 `/PanBox` → 取直链 → 下载 → 自动删除副本」，
转存前先给目录拍快照，**你自己原有的同名文件绝不会被误删**，未完成的任务不回收（还要续传）。

## 浏览器插件

插件在 `resources/extension/`，随安装包发布，**需要手动装一次**：

设置 →「浏览器插件 → 打开插件文件夹」→ 浏览器打开 `chrome://extensions`（Edge 是 `edge://extensions`）
→ 开**开发者模式** → **加载已解压的扩展程序** → 选那个 `extension` 文件夹 → 点插件图标 → 「重新配对」。
更新插件后要回扩展页点一次**「重新加载」**（已解压的扩展不会自动更新，Chrome 137 起命令行侧载也被禁用）。
便携版会把插件抄一份到程序旁边的 `PanBox插件` 文件夹（路径固定，重启后仍有效），「打开插件文件夹」指向的就是它；安装版用的还是包内那份。

抓回来的文件**后缀可能是错的**（网页不给真名、有的站点还发假后缀）—— 这不是下载出错，**自己改一下后缀就能用**，见本节末尾。

- **页面左上角「N 个文件」悬浮面板**：列出这一页能下的东西 —— 正在播放的视频/音频真实地址、`.m3u8`、
  页面里的图片、`.zip` / `.apk` / `.pdf`；点「下载」直接进 PanBox。按响应头 `Content-Type`
  认媒体而不是看后缀（抖音的地址路径里根本没有 `.mp4`），单页应用换视频会自动重扫，✕ 只是暂时收起。
  B 站 / YouTube 用 MSE，`<video>` 上是 `blob:` 地址，任何下载器都拿不到，面板会改列抓到的分片。
- **面板按类型分组**：`视频 / 播放列表` · `图片` · `其他文件` · `分片`，东西多了还多一个搜索框；
  **分片默认折起来**（`.ts` / `.m4s` 是视频被切开的其中一片，**单独下下来必然打不开**，要下就在
  「视频 / 播放列表」里选那一页的 `.m3u8`，PanBox 会自己拼成完整视频）。
- **图片**：把这一页的图（含懒加载与 `srcset` 里的大图）列出来，正在播放的那条标「正在播放」；
  X（Twitter）/ Pinterest 的图会自动换成**原图**地址（行上带「原图」徽章）；个别图的原图地址不存在时会下不下来，
  那一张右键另存即可。
- **分离了音轨的视频**（X / 部分 CMAF 站点把画面和声音放在两条 `.m3u8` 里）：PanBox 会两条一起下、
  自己合成一个带声音的 `.mp4`；合不起来时如实存成两个文件并说明，而不是默默给你一个没声音的视频。
- **接管浏览器下载**（默认开启）：浏览器里点任何下载都转进 PanBox；PanBox 没运行就放回浏览器。
- 投递过来的是**网盘分享链接**时，PanBox 把链接预填进输入框，让你自己勾选。
- 投递时插件还会把**当前页面的浏览器现场**（真 User-Agent、该主机自己的 cookie、浏览器那次的 Referer）
  一并交给 PanBox：取分享页、文档、清关页时照着浏览器刚才是怎么发的发，反爬那关就不再靠逐站硬猜。
  现场**只存在内存里、10 分钟不用就丢**，不写进任何配置或任务记录；**账号接口仍然只用设置里那份凭证** ——
  浏览器里登录的可能是另一个账号，两套会话不混在一个请求里。

### ⚠️ 抓下来的文件后缀不对、打不开？自己改一下后缀就行

不少网页不给真实文件名，插件只能沿用页面上的名字（有的站点还故意发假后缀），存下来的后缀因此可能是错的 ——
**不用重下，在文件上右键 →「重命名」，把后缀改成正确的格式即可**：

| 实际是什么 | 改成 |
|---|---|
| 压缩包 | `.zip` / `.rar` / `.7z` |
| 视频 | `.mp4` / `.mkv` / `.flv` |
| 音频 | `.mp3` / `.m4a` / `.flac` |
| 文档 / 电子书 | `.pdf` / `.epub` / `.docx` |

看不到后缀时，先在资源管理器里打开「显示文件扩展名」（**查看 → 显示 → 文件扩展名**）再改。
改完若还打不开，多半是文件本来就没下完整，删掉重下一次。

## 网络出口（下 GitHub / 境外资源必看）

默认**跟随 Windows 系统代理**（读注册表，Clash 换端口自动跟），也可以手动指定或不使用。
同一条 GitHub 66 MB 直链实测：直连 `github.com` 约 0 B/s（SNI 层间歇被重置）→ 走系统代理 **9.5 MB/s**（7 秒）；
不用代理也能下：空档看门狗（3 秒没新数据就换连接）+ 重定向只解一次，128 连接 **3.0 MB/s**。
分段引擎在探测阶段按「代理 → 直连」各试最多 3 次，选中哪条整条任务都用它，任务行会标出「· 走代理」。
代理**只给普通直链任务** —— 网盘直链可能按 IP 授权，不拿它冒险。

## 自定义解析接口（可选）

内置解析的天花板是**你自己账号的档位**。如果你愿意信任某个第三方解析服务，可以在
「设置 → 高级：解析接口」让它转发。地址与请求体支持 `{url}` `{pwd}` `{shareId}` `{netdisk}` 占位符，
POST / GET 都行；响应的 `url` / `dlink` / `directLink` / `download_url` 等字段与嵌套数组都能识别，
认不出来可以手填字段路径；302 自动跟。配了就优先走接口，**接口挂了自动退回内置解析**。
首次启用必须勾选用户承诺才能保存。

**合规边界**：PanBox 是下载客户端 —— 不内置、不推荐任何解析站，不代收费用或分成，不做破解会员 / 秒传 /
伪造身份 / 变速外挂，不帮助批量获取或转售他人资源。请只用它下载**你自己有权下载**的内容；接口地址由你
自己提供并自行确认合法性（PanBox 只做 HTTP 转发，不看、不存、不校验它返回什么）。**你自己的网盘 Cookie
只在本机使用，不会发往接口**（填了提取码时，提取码会随分享链接一起发给该接口）。

## 常见问题

**速度为什么没有突破网盘限制？** 做不到，限速是服务端按账号等级决定的。"加线程有没有用"逐盘标定，见上表。

**会读取 / 上传我的账号信息吗？** 不会。凭证只存在本机 `%APPDATA%\PanBox\settings.json`，
所有请求直接发往网盘官方接口，没有中间服务器。

**插件抓下来的文件后缀不对、打不开？** 改一下后缀就能用 —— 右键 →「重命名」，换成真实格式（做法与常见对照表见
上面「浏览器插件 → 抓下来的文件后缀不对、打不开？」一节），不必重下。

**投进去的明明是视频页面，下下来却是个网页（`.html`）？** 那是**页面地址**，不是文件地址：服务器回的就是网页本身，
PanBox 如实存成 `.html` 并提示一句，所以它当然放不出画面。正确做法是**先把视频播起来**，再用插件面板从
「视频 / 播放列表」里选那一条（`.m3u8` 会被拼成完整视频；`.ts` / `.m4s` 只是其中一片，单独下下来打不开）。
YouTube / B 站这类用 MSE 的站点，画面在 `<video>` 里以 `blob:` 播放，任何下载器都拿不到整段，面板列出的就是
它当场请求的播放列表或分片；Pinterest 同理 —— 视频没播过，页面源码里根本没有那个 `.mp4`。

## 技术栈与构建

Electron 44（`contextIsolation: true`、`nodeIntegration: false`）+ React 19 / TypeScript / Vite 8；
下载引擎是内置 **aria2 1.37.0**（JSON-RPC，随机 token，只监听 `127.0.0.1`）加自研分段引擎；
`electron/parsers/` 下每个网盘一个纯 Node 解析模块。

```bash
npm install
npm run build:renderer                   # 渲染层
node node_modules\typescript\bin\tsc --noEmit -p tsconfig.json
npm run pack                             # 打包 NSIS + portable，产物在 release\
```

`resources/aria2/aria2c.exe` **不在仓库里**，需自行下载 aria2 1.37.0 win-64 放到该路径。

```
electron/                  主进程（CommonJS）
  main.js                  BrowserWindow + 全部 IPC + 转存副本回收
  preload.js               contextBridge → window.panbox
  core/                    aria2 segmentDownloader taskManager settings login bridge proxy trash netHosts
  parsers/                 index sites.json util esa esaSolve browserCtx identity probe transferReclaim
                           lanzou ilanzou clouddrive quark uc pan123 baidu xunlei mdpi ssrn direct custom
src/                       渲染层（React + TS）
resources/extension/       浏览器插件（MV3）
resources/aria2/           aria2c.exe（自行下载，不入库）
```

### 已知限制

- 夸克 / UC / 百度 / 迅雷 / 阿里云盘 / 天翼云盘 / 移动云盘**取下载地址必须登录**，
  游客直链会被 CDN 拒绝（412 / 403 / 401）；例外的是「列目录」这一步：阿里云盘 / 移动云盘
  匿名就能列，天翼云盘只有**单文件**分享能匿名列（文件夹分享要登录，服务端直接回
  `Argument invalid` / `InvalidSessionKey`）。
- **账号级限速是硬天花板**，内置解析拿到的速度取决于你自己账号的档位。
- **123 云盘**受分享者每月 10 GB 提取配额限制；**115 / 微云**尚未实现（这一轮没做）。
- 移动云盘的网页端把登录令牌藏在一个懒加载 chunk 里，没查出稳定取值位置，所以它不做
  「一键登录窗」，只能手贴凭证（设置 →「网盘账号」→ 移动云盘的凭证框）：粘
  `Authorization` 的值，形如 `Basic <base64("pc:账号:令牌")>`（解析器也认裸的 base64 串）。
- 未做代码签名，首次运行会触发 SmartScreen。

### 解析规格来源（许可证要求的署名）

PanBox 借鉴以下项目公开的**本地解析算法实现**（用于 `electron/parsers/` 里的离线计算），
**不调用**、**不推荐**、也不链接它们的任何在线服务；署名不代表对其服务可用性与合规性的背书。

- 蓝奏云 / 蓝奏优享 / 123 云盘：`qaiu/netdisk-fast-download`（`LzTool.java` / `IzTool.java` / `AESUtils.java` / 签名算法）
- 夸克 / UC：`qaiu/netdisk-fast-download`（`QkTool.java` / `UcTool.java`）、`muyan556/gopeed-extension-quark`（MIT）
- 百度网盘：`pan.baidu.com/union` 开放平台文档 + 社区实现
- 移动云盘：`OpenListTeam/OpenList`（`drivers/139`，AES-128-CBC 请求体加密、三个分享接口与请求头）
- 天翼云盘：`cloud.189.cn` 的 H5 分享页 + 21CN 订阅 SPA 的请求拦截器（签名算法），
  接口字段以本机实测为准
