PanBox 下载助手 —— 浏览器插件（Chrome / Edge）
=================================================

这个文件夹就是插件本体，不需要去商店安装，也不需要编译。

装法（大约 30 秒）
-----------------
1. 打开浏览器，地址栏输入：
     Chrome :  chrome://extensions
     Edge   :  edge://extensions
   回车。
2. 打开右上角（Edge 是左下角）的「开发者模式」开关。
3. 点「加载已解压的扩展程序」（Edge：加载解压缩的扩展）。
4. 选中本文件夹（就是你现在看到的这个目录），确定。
5. 工具栏上会出现一个蓝色下载图标。第一次点它，它会自动跟本机 PanBox 配对。
6. 以后升级了 PanBox，回到 chrome://extensions 点一次「重新加载」即可。

用起来
------
- 在任意链接 / 视频 / 音频上点右键 → 「用 PanBox 下载此链接」
- 在页面空白处点右键 → 「用 PanBox 下载本页所有文件链接」
  （只挑 .zip/.rar/.iso/.exe/.mp4/.pdf 这类一看就是文件的链接）
- 选中一段含链接的文字再右键 → 「用 PanBox 下载选中的链接」
- 想让浏览器所有的下载都自动转给 PanBox：点插件图标，打开
  「接管浏览器下载」。默认开着；随手存个小图不想被拦，就把它关掉。
- 页面右下角会浮出一个小面板，列出这一页能下的文件；标题栏可以拖动，
  位置会记住。

任务会立刻出现在 PanBox 的下载队列里，而且会带上当前页面的
Referer / Cookie / User-Agent —— 很多网站的直链离开这几个请求头就是 403，
这也是浏览器自己的下载器交不出来的东西。

连不上？
--------
- 先确认 PanBox 正在运行。插件是主动连 PanBox，PanBox 不开就没有人接。
- 点插件图标看状态：显示「已连接 PanBox · 127.0.0.1:7799」才正常。
- 如果端口被占用（PanBox 设置里会提示），把插件高级选项里的端口改成一样。
- 还是不行就在 PanBox 的「设置 → 浏览器插件」里点「重新配对」，
  再把那一串令牌复制到插件的高级选项里。

注意
----
- 只支持 Chrome / Edge 这类 Chromium 内核浏览器。Firefox 的插件格式不一样，
  在 Firefox 里加载本文件夹会失败。
- 插件只做「把请求转交给本机程序」这一件事：不改网盘限速、不碰会员权限，
  下载速度就是你自己账号的档位（PanBox 只是把它跑满，并加上多线程与断点续传）。
- 插件不收集、不上传任何数据。它说的话只有 127.0.0.1 上的 PanBox 听得见。
